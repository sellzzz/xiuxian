# 太虚问道项目规划

## 一、当前产品定位

这是一个类似《王权：三国》的修仙卡牌叙事游戏：每张卡牌代表一个半年节点，左右选择改变此世状态，向上滑代表闭关修炼。主线围绕“拜入青云宗 → 杂役求生 → 外门与内门 → 宗门兴衰 → 魔域远征 → 飞升或留守”展开。

## 二、系统地图

| 系统 | 当前职责 | 后续扩展方向 |
| --- | --- | --- |
| 卡牌事件 | 左右选择、锁定选项、事件池和主线闸门 | 事件标签、章节包、条件编辑器 |
| 时间与寿元 | 每次行动半年、寿元消耗、延寿丹恢复、状态持续时间 | 年龄阶段、特殊时间线 |
| 属性与境界 | 灵力、气血、声望、灵石、道心、灵根、境界 | 五行克制、功法流派、境界突破分支 |
| 功法与装备 | 功法熟练度、装备槽、兵刃和法宝栏位 | 法宝主动技能、套装、炼器和强化 |
| 人缘册 | 三名人物好感、牵连变化、人物因果线索 | 更多人物、阵营、送礼、关系事件编辑 |
| 因果系统 | 灵泉、税赋、药童及人物多年回应 | 多年伏笔链、条件结算、因果回溯 |
| 道途系统 | 仁心、逆命、权衡三条道途 | 道途专属事件、技能、结局和冲突 |
| 宗门系统 | 任务、贡献、门人、阵势、库藏和掌教主线 | 七峰经营、弟子培养、宗门外交 |
| 秘境与远征 | 秘境三段探索、魔域远征、法宝奖励 | 随机地图、队伍编成、资源消耗 |
| 轮回与结局 | 结局图鉴、传承选择、跨世统计 | 多周目解锁、轮回天赋、隐藏结局 |
| 音频与表现 | 背景音乐、音量、场景音色、打坐动画 | 事件主题音乐、音频资源配置化 |

### 已完成的工程化能力

- 法宝栏位支持配置驱动扩展：在 `config/story-config.js` 注册后，可通过剧情或 `QingyunStoryAPI.grantArtifact()` 获得，并自动参与属性计算。
- 存档包含版本号和兼容迁移，新增字段不会破坏旧存档。
- 背景音乐音量与开关会保存在本地，自动存档在页面进入后台时立即落盘。
- `tests/smoke-check.ps1` 与 `tests/validate-config.js` 已接入 GitHub Actions，推送时自动检查资源、脚本、CSS 和剧情配置。

## 三、推荐开发顺序

### 阶段 A：内容基础

1. 把现有 `src/app.js` 中的事件数据逐步迁移到独立剧情配置文件。
2. 为每张卡牌补充唯一 ID、章节、标签、前置条件、左右结果和后续影响。
3. 建立人物、法宝、功法、状态、结局的独立数据表。

### 阶段 B：核心可玩性

1. 完成五行灵根与功法属性的克制关系。
2. 增加法宝主动使用与冷却，不只作为被动展示。
3. 扩展人缘册：人物阵营、相互关系、送礼和专属事件。
4. 把因果线索做成可追踪的多节点链。

### 阶段 C：内容规模化

1. 以“章节包”组织事件：第一幕、外门、秘境、宗门危局、魔域、飞升。
2. 每个章节独立维护事件、背景、音效、奖励和结局条件。
3. 增加调试面板：跳年、指定事件、修改属性、导出存档。

### 阶段 D：质量与发布

1. 建立新档、旧档、第一幕、法宝、人物联动、结局的回归测试。
2. 统一资源命名和尺寸，压缩背景图，避免首屏加载过慢。
3. 增加版本号和存档迁移函数，防止后续字段变化破坏旧存档。

## 四、核心开发约定

- 新剧情优先写入 `config/`，核心循环只负责执行，不直接堆叙事文本。
- 新资源放入 `assets/` 对应分类，文件名使用英文小写和短横线。
- 新系统先写状态字段、初始化默认值、存档兼容，再写 UI。
- 所有主线必定触发的事件都要有明确的 `currentEvent()` 闸门。
- 所有可能影响旧存档的字段，都在 `loadGame()` 中提供默认值。
- 人物好感修改必须经过统一的人际联动函数，避免剧情直接改写多个字段。
- 每次改动后至少验证：脚本语法、资源路径、页面加载、核心点击流程。

## 五、推荐的下一次重构

当前 `src/app.js` 仍是单文件运行版本，适合快速迭代但不适合长期扩展。下一次可以按以下顺序拆分，不改变游戏行为：

1. `src/state/`：初始状态、存档、迁移。
2. `src/systems/`：修炼、关系、因果、道途、宗门、秘境。
3. `src/content/`：事件和人物数据。
4. `src/ui/`：渲染、拖动、动画、音频。
5. `src/main.js`：只负责初始化和模块装配。

当前入口仍是根目录 `index.html`；样式已拆分为 `styles/base.css`、`styles/visual-polish.css` 和 `styles/ui-overrides.css`，剧情扩展统一从 `config/story-config.js` 接入。
