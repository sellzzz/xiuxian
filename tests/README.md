# 回归测试清单

- 新档可以进入第一幕，左侧禁止向左和向上。
- 第一幕结束后功法、背包和任务解锁。
- 修行第 2 年必定触发人缘册偶遇。
- 人缘册获得前左侧法宝栏隐藏，获得后出现封面和空槽位。
- 点击人缘册可以打开，关闭后回到卡牌页面。
- 人缘册显示三个人物好感、牵连变化和因果线索。
- 秘境法宝、羁绊信物可以填入左侧空法宝槽。
- 旧存档缺少新字段时可以正常加载。
- 音乐开关、音量、打坐动画和背景图不报错。
- `node --check src/app.js` 通过，CSS 括号平衡。

## 自动检查

在项目根目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File tests/smoke-check.ps1
```

该检查会验证关键目录、页面节点、脚本语法和 CSS 花括号，适合每次新增剧情或法宝后快速回归。

GitHub 上的每次推送和 Pull Request 也会自动运行同一套检查。
